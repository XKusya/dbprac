**Концепция**

Веб-сервис, который предоставляет организаторам набор инструментов для создания, управления и проведения любых видов соревнований.

**Сценарии использования**

1. Создание серии соревнований (Series)
Организатор (Planner) создаёт страницу серий для нового мероприятия (Series), создаёт отдельные события (Event) указывает вид спорта (Discipline), место, дату и условия участия. 

2. Регистрация участника (Athlet)
Спортсмен (Athlet) регистрируется на соревнование. Система создаёт запись в таблице AthletRegistration, фиксируя его участие и статус оплаты. 

3. Регистрация команды (Team)
Команда (Team) из нескольких участников (TeamMember) регистрируется на соревнование. Система создаёт запись в таблице TeamRegistration, фиксируя участие команды и статус оплаты. 

4. Публикация результатов (MatchupResult)
После завершения соревнования организатор вводит результаты в таблицу MatchupResult. Эти результаты становятся мгновенно доступны для всех пользователей. К тому же становятся известны участники занявшие призовые места и их награда

5. Автоматическая генерация списков участников
Система автоматически формирует списки зарегистрированных спортсменов и команд для каждого соревнования, используя данные из таблиц  AthletRegistration и TeamRegistration.
